# 🌦 Project: Weather API

### Goal: Enable your user to enter a city + country and return the temperature in Fahrenheit

![Screenshot of front page of web app](assets/Simple%20Weather%20App.png)

### Project Description  
- This simple weather app uses a weather API that takes in the city and state as query parameters. It then shares the current temperature at that location. 
- The styling is bright and inviting without being too jarring.
### Tech Stack Used
- HTML, CSS, JavaScript
